# Shared Agent Baseline

This is Friday's tool-neutral shared baseline. Consumer repositories may add
their own overlays after reviewing it.

- General work: read [`docs/agent-rules.md`](docs/agent-rules.md).
- Git safety, commits, and pull-request evidence: read the relevant document
  in [`docs/git-guideline/`](docs/git-guideline/).
- Scratch files, handoffs, retrospectives, snapshots, and pull-request
  evidence paths: read [`docs/scratch-files.md`](docs/scratch-files.md).
- Use an installed Git skill only when its own invocation conditions apply.
